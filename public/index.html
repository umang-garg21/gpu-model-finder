About Fit to Metal

Find the best open-source AI model for your GPU — instantly.

What it does

Fit to Metal lets you select your GPU (or enter a custom VRAM budget) and instantly surfaces every open-source model that will fit, ranked by benchmark quality. It covers LLMs, image generation, audio/speech, computer vision, video, and embedding models.

How VRAM estimation works

Each model's memory footprint is estimated from its parameter count and the selected precision:

PrecisionBytes / paramExample — 70 B model
FP324≈ 280 GB
FP16 / BF162≈ 140 GB
INT81≈ 70 GB
INT4 / GGUF Q40.5≈ 35 GB
GGUF Q81≈ 70 GB

A 20 % overhead is added for KV-cache and activations (minimum 0.5 GB). Estimates are approximate — actual usage varies with context length, batch size, and framework.

How benchmark ranking works

Rather than averaging raw scores across benchmarks, Fit to Metal normalises each score against the known frontier ceiling for that benchmark, then weights by difficulty². This means a model scoring 30 % on Humanity's Last Exam (frontier ceiling ≈ 35 %) ranks far above one scoring 90 % on MMLU (frontier ceiling ≈ 92 %), because HLE is genuinely harder and discriminates at the frontier.

BenchmarkDifficultyFrontier ceilingCapability domain
Humanity's Last Exam (HLE)5 / 5≈ 35 %Reasoning & knowledge
GPQA Diamond4.5 / 5≈ 90 %Scientific reasoning
SWE-bench Verified4 / 5≈ 77 %Coding (real issues)
GAIA4 / 5≈ 75 %Agentic tool-use
GDPval-AA4 / 5≈ 60 %Agentic real-world tasks
MATH3.5 / 5≈ 90 %Competition math
HumanEval3 / 5≈ 95 %Python code generation
GSM8K2.5 / 5≈ 98 %Grade-school math
MMLU2.5 / 5≈ 92 %General knowledge
ARC Challenge2 / 5≈ 96 %Science reasoning
IFEval2 / 5≈ 95 %Instruction following

Within each capability domain (reasoning, coding, math, agentic, instruction-following) only the hardest available benchmark is used, so a model with both MMLU and GPQA data won't have its GPQA score diluted by the easier MMLU score.

Data sources

  • HuggingFace API — model discovery, download counts, model cards, parameter metadata
  • ArtificialAnalysis.ai — standardised benchmark scores run under controlled conditions
  • Curated BENCHMARK_DATA — hand-verified scores for 150+ flagship models from official model cards and published papers

Privacy Policy

Short version: we collect nothing about you.

No personal data collected

Fit to Metal does not collect, store, or process any personal information. There are no user accounts, no login, no cookies, and no local storage beyond your browser's in-session state.

No analytics or tracking

There are no analytics scripts, no tracking pixels, and no third-party advertising tags on this site. Your usage is not recorded.

Third-party API calls

When you perform a search, the server fetches model metadata from HuggingFace. Your IP address is used to make these requests server-side; HuggingFace's own privacy policy applies to their infrastructure. No query parameters or personal data are forwarded beyond what is necessary to fetch model lists.

Benchmark data from ArtificialAnalysis.ai is fetched periodically by an automated script and cached locally — it is not fetched per user request.

Hosting

This application is hosted on Railway. Railway's infrastructure and privacy practices are described at railway.app/legal/privacy.
